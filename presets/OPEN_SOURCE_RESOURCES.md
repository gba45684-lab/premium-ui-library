# Open-source UI/UX resources

Verify each project's current license, supported framework, maintenance and component-specific terms before adoption. These projects are not interchangeable.

- shadcn/ui — https://github.com/shadcn-ui/ui
- Radix Primitives — https://github.com/radix-ui/primitives
- Magic UI — https://github.com/magicuidesign/magicui
- Aceternity UI — https://github.com/aceternity/aceternity-ui
- React Spectrum / React Aria — https://github.com/adobe/react-spectrum
- Mantine — https://github.com/mantinedev/mantine
- Material Components for the web — https://github.com/material-components/material-web
- Tailwind CSS — https://github.com/tailwindlabs/tailwindcss
- Lucide icons — https://github.com/lucide-icons/lucide

Do not assume that every showcased component, asset, font or example is open source under the same license. Use official installation instructions and respect attribution and license obligations.
