# UI/UX review checklist

- [ ] Existing functionality and navigation preserved
- [ ] Primary style preset selected and applied consistently
- [ ] Shared tokens used instead of scattered values
- [ ] Mobile and responsive layouts checked
- [ ] Contrast, focus and keyboard navigation checked
- [ ] Touch targets and labels checked
- [ ] Loading, empty, error, success and disabled states considered
- [ ] Reduced-motion preference respected
- [ ] Blur, gradients, shadows and animation are purposeful
- [ ] No unlicensed assets or copied proprietary UI
- [ ] Available lint, type-check, tests and build run
- [ ] Pull request summarizes changes and limitations
