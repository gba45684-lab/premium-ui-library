# UI/UX instructions for this app

For UI/UX tasks, use the central design reference:
https://github.com/gba45684-lab/premium-ui-library

Read before redesigning:
- https://github.com/gba45684-lab/premium-ui-library/blob/main/UI_UX_RULES.md
- https://github.com/gba45684-lab/premium-ui-library/blob/main/presets/STYLE_PRESETS.md
- https://github.com/gba45684-lab/premium-ui-library/blob/main/presets/OPEN_SOURCE_RESOURCES.md

Rules:
1. Inspect this app's actual framework, routes, components, dependencies and build/test commands before edits.
2. Preserve existing features, data, navigation, APIs, ads, purchases, authentication and platform behavior.
3. Choose one primary style preset and at most one supporting motif; justify the choice briefly.
4. Use only compatible dependencies and verify current licenses.
5. Keep mobile and desktop responsive, accessible and performant.
6. Respect reduced motion, focus visibility, contrast and touch targets.
7. Run available checks; never claim tests passed unless they ran successfully.
8. Prefer a feature branch and pull request. Do not force-push or silently replace production code.
